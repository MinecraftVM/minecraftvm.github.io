修复 ​

适用于ColorOS15~16.1

​

1.开机卡小布 ​

odm/etc/build.prop里面添加 import /odm/build.prop import /odm/etc/${ro.boot.prjname}/build.gsi.prop import /odm/etc/${ro.boot.prjname}/build.${ro.boot.flag}.prop import /mnt/vendor/my_product/etc/${ro.boot.prjname}/build.${ro.boot.flag}.prop 再将原包odm/build.prop添加进原机同目录

2.挖孔修复（修复流体云位置） ​

在原机系统中打开开发者设置 然后找到指针位置 挖孔的上下左右都量一遍按照这样的格式填 ro.oplus.display.screenhole.positon=左x,上y,右x,下y 例如我的小米13数值就是505,29:575,99 505对应挖孔左边x轴其他同理

3.挖孔遮罩修复 这边提供两种方法 ​

如果你是屏幕边缘没有坏点的机子 按照如下 打开system/my_product/etc/permissions/oplus.product.display_features把其中带corner的feature删掉 如果你是屏幕上有坏点的机子 如:小米13 打开先找到原机的product/etc/overlay/devicesoverlay.apk 然后打开/res/drawable/我们可以看见里面会有遮罩 然后我们打开ps或者什么画图软件 把上下左右四个角的遮罩全部按照正方形的截出来 中间的挖孔也是 然后找到 system/my_product/overlay/oplus_framework_res_overlay.display.product.xxxxx.apk 把你截图出来的四个角和挖孔替换 这边解释一下名字oplus_rc_bottom_left就是左下角 oplus_rc_cutout就是挖孔

4.状态栏高度修复 ​

system/my_product/overlay/android_framework_res_overlay.display.product.xxxxx.apk里面的resources照着product/overlay/DevicesAndroidOverlay.apk里面的数值改

5.dpi修复 ​

system/my_product/build.prop里面的 ro.sf.lcd_density改成原机对应

6.音量键位置 ​

system/my_product/persist.oplus.software.audio.right_volume_key如果你的音量键在右边就true 左边就false

7.相机参数 ​

odm/build.prop ro.vendor.oplus.camera.frontCamSize=前置 ro.vendor.oplus.camera.backCamSize=后置

8.屏幕大小 ​

odm/build.prop ro.oplus.display.screenSizeInches.primary=原机

9.机型显示 ​

ro.vendor.oplus.market.name=中文名 ro.vendor.oplus.market.enname=英文名

10.处理器参数: ​

ro.build.device_family=op+代号 ro.product.oplus.cpuinfo=代号

11.电源键延迟 ​

补hal不多赘述 自行解决

12.电压异常 电池容量 ​

原包odm/etc/power_profile文件夹扔原机 打开里面的power_profile.xml搜battery.capacity 数值改成原机

13.振动 ​

补lib不多赘述
